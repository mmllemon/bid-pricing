# 用户操作界面第一版实现说明

## 技术选择

第一版采用 Streamlit。它适合当前项目的原因是：

1. 现有核心是 Python，上传、校验、MILP 求解和 Excel 解析可以直接复用；
2. 不复制业务规则，前端只负责参数、状态和结果展示；
3. 可在本地或内网快速启动，适合先验证报价人员的工作流；
4. 后续需要账号、权限、多人协作时，可保留 `src/bidpricing` 内核，将前端替换为 Vue/React + FastAPI。

## 已实现功能

- 上传限价清单和成本清单 Excel；
- 自动识别固定表头并解析项目编码、工程量、综合单价；
- 显示匹配数量、未匹配项、重复项、空最高限价等异常；
- 输入目标总报价、固定金额和税率；
- 运行 C13（最高限价基准、±50%、结算调整）Phase 2 MILP；
- 展示综合单价、报价合价、竞争性预算和结算调整后利润；
- 下载当前计算结果 JSON。

## 启动

```powershell
python -m pip install -r requirements-ui.txt
$env:PYTHONPATH = "src"
streamlit run app/streamlit_app.py
```

## 当前边界

当前 C13 MILP 需要有限最高限价才能判断 50% 严重低价区间。因此，空最高限价会被识别并提示，但暂不自动进入 C13 求解；这不是把空值当作 0。下一步应增加“无最高限价项人工报价/固定上限”输入，并生成正式 Excel 结果而不是只下载 JSON。
