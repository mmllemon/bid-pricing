# ADR-0012：q1 是预测不是事实 —— 声明的重心不是「谁说的」

- 状态：**已接受**（2026-09-17）
- 关联：ADR-0002（机制 vs 数据分时点判）、ADR-0004（未定态不得降级为默认值）、
  ADR-0011（附证交叉满足）、T00-10A / T00-10B / T00-11、OI-06

---

## 背景

T00-11（c_i 假设声明书）建立了「来源 / 格式 / 冻结时点」三要素骨架。
T00-10A / T00-10B 的任务标题与其高度同构（「格式篇 + 来源篇」），
直接照搬是最省事的做法——**但会得出一个无信息量的答案**。

两者性质根本不同：

| | c_i（成本单价） | q1（结算工程量） |
|---|---|---|
| 时点 | 已发生（询价已做、结算已有） | **未发生**（竣工后按实确定） |
| 可观测性 | 投标期可取得 | 投标期**不可观测** |
| 错误性质 | 数据错了 / 来源不可信 | 预测偏了 |
| 声明重心 | **谁说的**（来源可信度） | **不确定性怎么表达**（点值 / 区间 / 场景集） |

对 q1 问「来源」必然得到「造价员估的」——无论是照搬成本库词表还是另设一套，
落点都一样，判据因此失去区分能力。

## 决策

1. **q1 声明书保留三要素骨架**，但第一要素不是 `source` 而是 `basis`（取值依据），
   词表为 `Q0_NO_CHANGE / COST_LISTING_QUANTITY / REDRAWN_QUANTITY /
   HISTORICAL_RATIO / EXPERT_ESTIMATE`——判的是**按什么算的量**，不是谁说的。
2. **格式（format）升为主要判据**：`POINT / INTERVAL / SCENARIO_SET` 与字段字典
   互锁（QB-04），格式是 q1 不确定性的唯一载体。
3. **点值假设强制承担敏感性义务（QB-05）**：`format = POINT` 而
   `sensitivity_requirement` 未声明 = **BLOCKED**。点值会把 P* 算成确定值，
   掩盖工程量风险——**预测被表达成确定值，精度就是虚假的**。
   词表 `RATIO_SCAN / SCENARIO_SWEEP / NOT_REQUIRED_JUSTIFIED`。
4. **`Q0_NO_CHANGE` 不得作为默认值**：它看似「最保守」，实为放弃工程量套利的建模，
   是实质性商务选择（ADR-0004）。未声明时 QB-01 判 BLOCKED 并明写此理由。
5. **格式不是独立声明，而是字段选择的推论**：本项目用户表述为
   「q1_point:=成本清单量」，选定 `q1_point` 字段即等价于 POINT，
   记为 `RESOLVED_BY_FIELD_BINDING` 而非用户另一次声明——避免同一事实两处录入。

## 为什么不是别的做法

| 备选 | 否决理由 |
|---|---|
| 照搬 c_i 的来源词表 | 五种来源对 q1 全部塌缩为「专家估计」，判据零区分度 |
| 只判格式不判取值依据 | 同一区间可以来自重算量也可以来自拍脑袋，可信度天差地别 |
| 允许 POINT 无敏感性义务 | P* 被算成确定值，而 q1 投标期不可观测——与 OI-06「修正价取名义值 + 敏感性」自相矛盾 |
| 把敏感性做成 WARN | 它就永远不会被做。真正想要的产出（P* 对 r 的敏感性曲线）必须由硬约束逼出来 |

## 与既有判据的关系

- **ADR-0011 跨文件复用**：「与 q0 差异归因」已由 `basis_declarations.json`
  的 `default_attribution`（DRAWING_DIFF）声明，QB-03 经 QB-02 判据**交叉满足**，
  不再重复索取；QB-02 为 WARN（UNKNOWN）时交叉满足**不成立**——归因不明等于没归因。
- **OI-06 同构**：10.4.1.3 修正价投标期不可知 → 名义值 + 敏感性扫描；q1 同理。
  两者共同构成「投标期不可观测量」的统一处理范式。

## 后果

- 正向：q1 的不确定性从「隐含在数字里」变成「显式声明 + 机器校验」。
- 代价：多一条 BLOCKED 判据（QB-05），在用户裁定敏感性义务前 Gate 0b 无法放行——
  **这是有意的**：q1 直接进目标函数，与 c_i 只影响约束不同。
- 现状（2026-09-17）：**用户裁定 RATIO_SCAN**，QB-05 解除。QB-01/02/04/05 PASS；
  QB-03 WARN（缺算量依据·图纸版本）；**QB-06 WARN（扫描网格未定）**；QB-07 WARN（未冻结）。

## 附：RATIO_SCAN 的网格必须来自数据，不能来自习惯

判据落地后实测真实样本（81 项双侧有量）：

| 指标 | 值 |
|---|---|
| r = 1.0 | 75 项 |
| r < 1（减量） | 6 项，最小 **0.4286** |
| r > 1（增量） | **0 项** |
| 金额加权 r | **0.9311** |

两点后果：

1. **±5% / ±10% 这类习惯性网格会漏掉全部真实偏差**——单项最大减量达 −57%。
   故 QB-06 要求网格覆盖已观测区间 [0.4286, 1.0]，并把该区间写进制品作为依据。
2. **r 的单向性（无一项 > 1）是待解释信号，不是结论**。若这 6 项减量源于
   **算量口径差异**而非真实预期，则 r 本身取错——而 r 是不平衡报价方向的
   唯一驱动（目标函数用 q1、约束用 q0，边际收益 ∝ r_i），方向一旦反向，
   整套报价结构反向。这正是 QB-03 索要「算量依据（图纸版本）」的理由：**该附证
   不是形式主义，它决定报价方向的正负**。
